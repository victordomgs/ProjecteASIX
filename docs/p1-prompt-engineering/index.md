## Objectius

- Entendre què és el prompt engineering i per què és un procés iteratiu.
- Identificar els components d'una instrucció: tasca, instruccions del sistema, exemples i context.
- Redactar instruccions estructurades a partir d'una plantilla.
- Detectar i corregir problemes de redacció, d'exemples i de disseny en una instrucció.
